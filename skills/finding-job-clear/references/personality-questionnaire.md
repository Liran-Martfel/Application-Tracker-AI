# Personality questionnaire (for the site's chat)

Recruiters ask the chat about character and work style ("How does she handle pressure?", "What kind of team does he want?"). The CV can't answer that, so this questionnaire does. Its answers become `knowledge/personality.md` in the site template.

## How to run it
- Ask in the user's language. The questions below are in Hebrew; translate them for other users. Hebrew questions use plural or neutral forms until the user's gender is known (it is asked first, because the chat speaks in their voice).
- Use AskUserQuestion: at most 4 questions per round, 2–4 options each (the user can always pick "Other" and write). Seven rounds, about 10 minutes. Say so up front, and that any question can be skipped.
- Open questions (marked ✎) are asked as plain chat questions after the round they belong to. Keep the user's own words: those become the quotes the chat repeats.
- Never guess an answer, never "improve" one, never add traits nobody said. A skipped question is simply left out.
- The answers are private data: they go only into the user's own site files.

## Round 1 — basics
1. איך הצ׳אט צריך לדבר בשמך בעברית? — בלשון זכר ("בניתי, אני מחפש") / בלשון נקבה ("בניתי, אני מחפשת") / ניטרלי ככל האפשר
2. איך חברים מתארים אותך? (אפשר כמה) — יוזם/ת / אכפתי/ת / אמין/ה / מצחיק/ה
3. מה אנשים הכי מעריכים אצלך? — שאכפת לי / שאפשר לסמוך עליי / שאני פותר/ת בעיות / שאני מביא/ה רעיונות
4. ✎ שלוש החוזקות שלך, במילים שלך. ✎ חולשה אחת שאת/ה מודע/ת לה ואיך את/ה מתמודד/ת איתה.

## Round 2 — work style
1. משימה חדשה שאת/ה לא מכיר/ה — קורא/ת תיעוד ומתכנן/ת / מתחיל/ה לנסות מיד / שואל/ת מישהו שעשה את זה / תלוי במשימה
2. הסביבה שבה את/ה עובד/ת הכי טוב — צוות קטן ומשתף / צוות גדול עם תהליכים / לבד, בשקט / שילוב: צוות עם זמן שקט לעצמי
3. דדליינים — מסיים/ת מוקדם ומשפר/ת / עובד/ת בקצב קבוע עד הסוף / הכי טוב תחת לחץ של הרגע האחרון
4. "מספיק טוב" או "מושלם"? — תמיד מושלם / מספיק טוב ואז משפר/ת / תלוי בחשיבות המשימה

## Round 3 — people and communication
1. התפקיד הטבעי שלך בצוות — איש/אשת הרעיונות / המוביל/ה / המבצע/ת / המגשר/ת
2. מחלוקת עם עמית/ה — מדבר/ת איתו/ה ישירות / מחכה שיירגע ואז מדבר/ת / מעלה למנהל/ת / תלוי במחלוקת
3. איך את/ה אוהב/ת לקבל משוב — בכתב / פנים מול פנים / שניהם, כל עוד הוא מקצועי
4. תקשורת — פנים מול פנים / הודעות כתובות / מציג/ה מול קהל בכיף / מעדיף/ה לא להציג

## Round 4 — pressure, problems and mistakes
1. משהו נשבר בזמן אמת — נשאר/ת רגוע/ה, מעדכן/ת ומחלק/ת משימות / קודם מתקן/ת בעצמי ואז מעדכן/ת / קורא/ת לעזרה מיד
2. טעות שלך — מנתח/ת, מתקן/ת ואז מדווח/ת / מדווח/ת מיד ואז מתקן/ת / תלוי עד כמה היא קריטית
3. תקוע/ה על בעיה — הפסקה קצרה וחוזר/ת / עובר/ת למשהו אחר וחוזר/ת מחר / מבקש/ת עזרה / ממשיך/ה עד שזה נפתר
4. ✎ סיפור קצר על בעיה קשה שפתרת, ומה למדת ממנה.

## Round 5 — leadership and teamwork
1. הובלת אנשים בעבר? — כן, בתפקיד רשמי / כן, בלי תואר / עוד לא
2. (אם כן) איך את/ה מוביל/ה — בדוגמה אישית / בהסבר של ה"למה" / בחלוקה ברורה של משימות / בתמיכה כשקשה
3. ✎ ממה את/ה הכי גאה בתור מוביל/ה או חבר/ת צוות?
4. ✎ מה תביא/י מהניסיון הזה לעבודה הבאה?

## Round 6 — what drives you
1. מה הכי מניע אותך — השפעה אמיתית / ללמוד ולגדול / צוות טוב / יציבות
2. ערכים מרכזיים (אפשר כמה) — יושרה / מקצועיות / אחריות / הגינות וכבוד
3. איפה את/ה רואה את עצמך בעוד חמש שנים — מומחה/ית טכני/ת / מוביל/ה צוות / מנהל/ת מוצר / עדיין מגלה
4. ✎ למה דווקא התחום הזה? (המשפט הזה הוא בדרך כלל הציטוט הכי חזק בצ׳אט.) ✎ משהו שלמדת לבד לאחרונה.

## Round 7 — what you are looking for, and outside work
1. סוג חברה — סטארט-אפ / חברה גדולה / חברה בינונית / לא משנה
2. היקף ומקום — משרה מלאה במשרד / היברידי / מהבית / גמיש
3. מתי אפשר להתחיל — מיד / תוך חודש / תוך כמה חודשים
4. ✎ תחביבים ומה את/ה עושה מחוץ לעבודה. ✎ הפרויקט האהוב עליך, ולמה.

## Turning the answers into `knowledge/personality.md`
- Third person ("She leads by example"), because the knowledge files describe the user; the chat turns it into first person when it answers.
- Fill the template's sections in order: one-paragraph portrait (written last, from the answers only), how others describe them, work style, people and communication, pressure, leadership, what drives them, what they are looking for, outside work.
- Keep ✎ answers close to the user's words, in quotes where they are striking. Short bullet lines, one fact each.
- Leave out anything private that a recruiter shouldn't read (health, family details, salary, other job processes). Ask before including reserve duty, religion or anything similar.
- Show the user the finished file and get their OK before it goes on the site.
- Note the month in the file's first line, so it is clear when the answers were given.
